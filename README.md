# Ржавые Рыцари

Мультяшная 3D-арена с видом сверху для Android. Рыцари бьются 3 на 3 во дворе замка.

**Режим «Зарядка».** В центре двора появляются кристаллы. Собери их и донеси до своего знамени (синие внизу, красные вверху). Если тебя победят, кристаллы выпадут. Побеждает команда, первой набравшая 10.

**Кусты.** Рыцаря в кустах не видно, пока враг не подойдёт вплотную или пока рыцарь сам не ударит. Кусты рядом с тобой становятся полупрозрачными.

**Управление.** Левая часть экрана — джойстик. Кнопка с мечом посылает волну меча с автоприцелом (можно держать). Кнопка-звезда — «Веер клинков» из 7 волн, заряжается от попаданий. На компьютере: WASD, пробел, E.

## Сборка APK на GitHub

1. Создай репозиторий на github.com.
2. Загрузи в него все файлы этой папки (включая скрытую `.github`), ветка `main`.
3. Вкладка **Actions** → «Сборка APK» запускается сама при каждом пуше (или кнопкой *Run workflow*).
4. Когда сборка позеленеет, скачай артефакт `rusty-knights-apk`, распакуй и установи APK на телефон.

## Запуск на компьютере

Godot 4.3 → открыть `project.godot` → F5.

## Структура

- `main.gd` — двор замка (текстовая карта), кусты, камера, кристаллы, счёт, интерфейс
- `knight.gd` — модель рыцаря, анимация ходьбы и удара, бой, ИИ ботов
- `bolt.gd` — волна меча
- `score_bar.gd` — табло со знамёнами
- `joystick.gd`, `touch_button.gd` — сенсорное управление
- `grass.png` (пол), `stone.png` (камень), `leaves.png` (листва), `bushes.png` (6 кустов-спрайтов) — текстуры
- `.github/workflows/build-apk.yml` — автосборка APK

Арену легко менять: это 20 строк символов в `MAP_TOP` в `main.gd` (`#` — камень, `b` — куст, `.` — трава), нижняя половина отражается автоматически.

## Звуки

Все звуки и музыка синтезированы скриптом `tools/make_sounds.py` (свои, без сторонних сэмплов):
`sfx_swing` (взмах), `sfx_hit` (удар по доспеху), `sfx_wall` (волна о камень), `sfx_death` (падение рыцаря),
`sfx_pickup` (кристалл), `sfx_score` (кристаллы сданы), `sfx_ready` (супер готов), `sfx_super` (веер клинков),
`sfx_win` / `sfx_lose` (конец матча), `sfx_click` (кнопка), `sfx_respawn` (возрождение), `music` (фоновая мелодия по кругу).
Далёкие звуки тише, у взмахов и ударов слегка меняется высота, чтобы не надоедали.

## Аккаунты и облачное сохранение (Firebase)

1. https://console.firebase.google.com → «Создать проект» (Analytics можно выключить).
2. Build → Authentication → «Начать» → Sign-in method → «Электронная почта/пароль» → включить.
3. Build → Realtime Database → «Создать базу данных» → регион europe-west1 → «Заблокированный режим».
   Вкладка «Правила» → вставить и опубликовать:
   ```json
   {
     "rules": {
       "users": {
         "$uid": {
           ".read": "$uid === auth.uid",
           ".write": "$uid === auth.uid"
         }
       }
     }
   }
   ```
4. Шестерёнка → «Настройки проекта» → «Общие» → скопировать «Web API Key».
   Адрес базы — вверху страницы Realtime Database (https://...firebasedatabase.app).
5. Вписать оба значения в начало `cloud.gd` (API_KEY и DB_URL).
